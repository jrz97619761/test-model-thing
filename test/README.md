# Test layout

`cli/` contains tests for `src/tmt/cli.py` and its command workflows. The files at the test root cover model, block, benchmark, and shared validation contracts.

## CLI tests

| File | Scope |
| --- | --- |
| `cli/test_commands.py` | Help, version, init, command dispatch, and the installed workflow |
| `cli/test_input_validation.py` | Invalid command inputs, early failures, and file preservation |
| `cli/test_config.py` | Config and checkpoint metadata checks for additional model fields |
| `cli/test_checkpoint.py` | Checkpoint names, shapes, dtypes, metadata, and round trips |
| `cli/test_generation.py` | Generated bytes, repeatability, seed boundaries, and temperature |
| `cli/test_training.py` | Train commands, resume, manifests, failures, and loss reports |
| `cli/test_telemetry.py` | Periodic samples, held-out scores, RNG preservation, and telemetry files |
| `cli/test_sweep.py` | Grid validation, candidate runs, results, and failure records |
| `cli/test_benchmark.py` | Benchmark command failures through both module entry points |
| `cli/conftest.py` | CLI subprocess, workspace, and manifest fixtures |

## Core tests

| File | Scope |
| --- | --- |
| `test_main.py` | Model arithmetic, RTU gradients, recurrence, losses, and frozen steps |
| `test_blocks.py` | Block contracts, custom gradients, state, and block integration with checkpoints and monitors |
| `test_evaluation.py` | Frozen byte scores, context windows, state restoration, and benchmark execution |
| `test_cola_validation.py` | CoLA row parsing and rejection before benchmark work |
| `test_validation.py` | Shared validator imports without MLX and error order |
| `conftest.py` | Shared model, checkpoint, and assertion fixtures |
| `fixtures/rtu-baseline.json` | Fixed RTU behavior for regression checks |

Core tests can use CLI helpers to create a model or checkpoint. Their assertions check the core contract.

The generation boundary test checks seeds `0` and `2**64 - 1`. The normal generation test uses seed `11` and checks repeatable output.

## Run tests

Run commands from the repository root with the project environment active.

```sh
python -m pytest
python -m pytest test/cli
python -m pytest test/cli/test_generation.py
python -m pytest test/test_main.py test/test_blocks.py
python -m pytest test/test_evaluation.py test/test_cola_validation.py
```

Pytest discovers both test groups from `testpaths = ["test"]` in `pyproject.toml`.
